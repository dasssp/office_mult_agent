# P1 核心能力优化说明

更新时间：2026-07-28

## 已完成

1. Supervisor 支持提示词定义的 14 类意图，并输出最小结构化执行计划。
2. Supervisor 可注入 `BaseChatModel`，模型输出必须通过 `RouteDecision` 校验；未配置模型时使用确定性路由。
3. `/assistant/invoke` 返回专业 Agent 的结构化结果，不再只返回路由提示。
4. `WorkEvent`、报告、转写、会议纪要、行动项、邮件分析和数据分析 Schema 已扩展。
5. 报告 Agent 支持日报/周报、事件去重、计划区分、低置信度与状态冲突提示。
6. 会议纪要支持决策和行动项证据、低置信度转写提示、版本及审核后 SHA-256。
7. 邮件润色支持附件、敏感信息、意图、期望动作、问题与修改说明。
8. 数据分析增加数值统计、重复行与空值质量提示，不会自动修改原始数据。
9. 企业 Connector Protocol 补齐会议 IM、ASR、Git、任务、组织目录、邮件状态和完整报工接口，并提供 Mock。
10. 文件支持 `xlsx/xls/csv/tsv/json/docx/pdf/txt/md`。
11. 分析产物可导出 Markdown、HTML、Excel、Word、PDF、CSV、SVG，并生成来源和统计口径元数据。

## 保持受控的边界

- Supervisor 不直接执行外部写操作。
- 邮件润色 Agent 不持有发送工具。
- 真实企业接口资料缺失时继续使用 Protocol 和 Mock。
- 统计指标由代码计算；模型只用于可选的意图分类和规划。
- 旧版 `xls` 仅解析数据，不执行宏、脚本或外部链接。

## 后续阶段

仍需在后续优先级中实现生产级任务队列、调度执行器、完整记忆管理 API、真实 Connector、对象存储、病毒扫描、模型生成后的事实一致性校验和端到端企业环境验收。
